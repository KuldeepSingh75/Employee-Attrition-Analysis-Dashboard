# Employee Attrition Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing employee attrition data to identify the key factors responsible for employees leaving the organization. The dashboard is created in Microsoft Excel using professional charts, KPIs, and data visualization techniques.

The analysis helps HR teams understand attrition trends and improve employee retention strategies.

---

# 🎯 Problem Statement
Analyze employee data to identify factors contributing to employee attrition such as:
- Age
- Salary
- Job Role
- Department
- Overtime
- Work-Life Balance

---

# 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design
- HR Analytics Dataset

---

# 📂 Dataset Information
Dataset Used:
HR Analytics Employee Attrition Dataset

The dataset contains:
- Employee Age
- Attrition Status
- Department
- Job Role
- Monthly Income
- Overtime
- Work-Life Balance
- Job Satisfaction
- Years at Company
- Education Field

---

# 📊 Dashboard Features

## KPI Cards
- Total Employees
- Attrition Count
- Attrition Rate
- Average Salary
- Average Employee Age

## Charts & Analysis
- Attrition by Department
- Attrition by Job Role
- Attrition by Age Group
- Overtime vs Attrition
- Work-Life Balance Analysis

---

# 🔍 Key Insights
- Employees working overtime have higher attrition rates.
- Younger employees are more likely to leave the company.
- Sales Executive and Laboratory Technician roles show higher attrition.
- Poor work-life balance contributes significantly to attrition.
- Lower salary employees are more likely to resign.
